# API source configuration

API request, response, pagination, and range configuration is now grouped
under [Source](source-patterns.md#api-source-configuration). The page keeps
the complete configuration flow in one place, with authentication still owned
by [Connections](connections.md#api-authentication).

For exact field types and allowed values, see the
[Source reference](../../reference/metadata-schema.md#source) and
[`source.configure`](../../reference/metadata-schema.md#dataflowssourceconfigure).
